# R7 Complete Engineering Station

This directory is the consolidated, non-destructive archive of the R7 work.

## Sections

- `implementation/r7_source/` — R7 implementation modules and replay entrypoint source.
- `harnesses/engine_a/` — Engine A reference harness.
- `harnesses/engine_b/` — Engine B Nautilus harness and tests.
- `harnesses/engine_c/` — Engine C Backtrader harness and tests.
- `harnesses/r7_replay/` — R7 replay harness.
- `reviews/chatgpt_codex/` — original audit report, matrix, diagnostics, metadata, and package evidence.
- `reviews/claude/` — Claude dispatcher and local execution-audit record.
- `reviews/gemini/` — isolated Gemini review workspace copy.
- `reviews/qwen_38/` — isolated Qwen 3.8 review workspace copy.
- `execution_audit/` — reserved for completed real execution-audit outputs.
- `metadata/` — complete file inventory and SHA-256 manifest.

Nothing was removed from the repository or from the earlier packages. This is a consolidated copy for inspection and sharing.
