DCS terms, mapped to the real identifiers above

PV
Process Variable — the live measurement a controller reads. Here: PA's confidence.
SP
Setpoint — the target the controller measures error against. Here: the rolling confidence baseline (_confidence_baseline), not a fixed constant.
MV
Manipulated Variable — the controller's output, the thing it actually adjusts. Here: entry_adjustment / exit_adjustment, or the ratcheted stop.
FB
Feedback path — the wire carrying the process's current state back to the controller's input. This is the wire that's missing on the left.

The line that makes it open-loop

240            self._execute_exit(symbol, timestamp, trade, float(bar["close"]), "max_hold_or_signal")
No PA signal, no confidence, no ContinuousExitController call anywhere in this function. held_bars ≥ minimum_hold_bars is a bare elapsed-time check — the label max_hold_or_signal promises a signal condition that is never actually evaluated.
