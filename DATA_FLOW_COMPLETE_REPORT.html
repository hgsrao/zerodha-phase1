1DATA INGESTION (Kite API → Redis)

When a new tick arrives for an equity symbol from NSE, it enters the ECS system through the Kite WebSocket API. This is the entry point for all real-time market data.

Process Flow:

  • 1.1 Real-Time Tick Arrives: Kite API receives tick from NSE exchange
  • 1.2 Tick Contains: Symbol, price, volume, timestamp
  • 1.3 Publish to Redis: Tick is published to Redis pub/sub channel
  • 1.4 Channel Name: ecs:ticks:INFY (symbol-specific)
  • 1.5 MainTradingLoop Subscribes: All subscribers receive the tick instantly

Code Implementation:

# From KiteOrderImbalanceConnector.py tick_data = { 'symbol': 'INFY', 'price': 1505.45, 'volume': 1000, 'timestamp': datetime.now(), 'ltp': 1505.45, 'open': 1502.10, 'high': 1506.50, 'low': 1502.00 } # Publish to Redis channel redis_client.publish( 'ecs:ticks:INFY', json.dumps(tick_data) ) # MainTradingLoop subscribes subscription = redis_client.pubsub() subscription.subscribe('ecs:ticks:INFY') for message in subscription.listen(): if message['type'] == 'message': tick = json.loads(message['data']) process_tick(tick) # Send to Stage 2

2ORDER IMBALANCE ANALYSIS (Lee-Ready Tick Classification)

The tick is analyzed using the Lee-Ready tick rule, which classifies each trade as either BUY or SELL based on price movement. This forms the foundation for microstructure analysis.

Step 2.1: Classify Individual Tick

  • If price > last_price → BUY (buyer initiated)
  • If price < last_price → SELL (seller initiated)
  • If price = last_price → Use prior tick direction (ambiguous)
# From OrderImbalanceCore.py - TickClassifier def classify(self, symbol, current_price, volume, timestamp): if self.last_price is None: self.last_price = current_price return {'tick_type': 'NEUTRAL', 'confidence': 0.0} # Lee-Ready Rule if current_price > self.last_price: tick_type = 'BUY' confidence = 1.0 # Certain classification elif current_price < self.last_price: tick_type = 'SELL' confidence = 1.0 else: # price == last_price tick_type = self.last_tick_type confidence = 0.5 # Ambiguous, 50% confidence self.last_price = current_price self.last_tick_type = tick_type classified_tick = { 'symbol': symbol, 'price': current_price, 'volume': volume, 'tick_type': tick_type, 'confidence': confidence, 'timestamp': timestamp } self.classified_ticks.append(classified_tick) return classified_tick

Step 2.2: Buffer Ticks (Last 5 Minutes)

Classified ticks are stored in a rolling buffer (deque with max 300 ticks ≈ 5 minutes). This allows historical analysis without storing unlimited data.

Step 2.3: Multi-Timeframe Imbalance Calculation

Instead of using a single window (which is noisy), calculate imbalance over 3 different windows and take the median. This is more robust to random fluctuations.

# From OrderImbalanceCore.py - ImbalanceCalculator def get_multi_timeframe_imbalance(self, symbol): # Calculate imbalance for 3 windows imb_30s = self.get_imbalance(symbol, 30) # 30-second window imb_60s = self.get_imbalance(symbol, 60) # 60-second window (primary) imb_120s = self.get_imbalance(symbol, 120) # 120-second window # Get median (robust to outliers) imbalances = [ imb_30s.get('imbalance', 0), imb_60s.get('imbalance', 0), imb_120s.get('imbalance', 0) ] median_imbalance = float(np.median(imbalances)) min_confidence = min( imb_30s.get('confidence', 0), imb_60s.get('confidence', 0), imb_120s.get('confidence', 0) ) return { 'imbalance_30s': imb_30s.get('imbalance', 0), 'imbalance_60s': imb_60s.get('imbalance', 0), 'imbalance_120s': imb_120s.get('imbalance', 0), 'imbalance_median': median_imbalance, 'imbalance_median_pct': median_imbalance * 100, 'confidence': min_confidence, 'heat_level': self._classify_heat(median_imbalance) } def get_imbalance(self, symbol, window_seconds): ticks = self.tick_history[symbol] now = datetime.now() cutoff_time = now - timedelta(seconds=window_seconds) # Get only ticks within the window recent_ticks = [t for t in ticks if t['timestamp'] >= cutoff_time] if len(recent_ticks) < 5: return self._empty_result(symbol, window_seconds) # Count BUY and SELL ticks (exclude NEUTRAL) buy_ticks = [t for t in recent_ticks if t['tick_type'] == 'BUY'] sell_ticks = [t for t in recent_ticks if t['tick_type'] == 'SELL'] buy_count = len(buy_ticks) sell_count = len(sell_ticks) total_count = buy_count + sell_count if total_count == 0: return self._empty_result(symbol, window_seconds) # Calculate imbalance: normalized to [-1, +1] imbalance = (buy_count - sell_count) / total_count # Example: If 60 BUY, 40 SELL # imbalance = (60 - 40) / (60 + 40) = 20 / 100 = +0.20 # imbalance_pct = +20% (buy pressure) buy_volume = sum(t['volume'] for t in buy_ticks) sell_volume = sum(t['volume'] for t in sell_ticks) # Confidence based on sample size confidence = min(total_count / 50, 1.0) return { 'timestamp': now, 'symbol': symbol, 'imbalance': imbalance, 'imbalance_pct': imbalance * 100, 'buy_count': buy_count, 'sell_count': sell_count, 'total_count': total_count, 'buy_volume': buy_volume, 'sell_volume': sell_volume, 'confidence': confidence, 'heat_level': self._classify_heat(imbalance), 'window_seconds': window_seconds } def _classify_heat(self, imbalance): abs_imb = abs(imbalance) side = 'BUY' if imbalance > 0 else 'SELL' if abs_imb > 0.30: return f'EXTREME_{side}' elif abs_imb > 0.20: return f'VERY_STRONG_{side}' elif abs_imb > 0.10: return f'STRONG_{side}' elif abs_imb > 0.05: return f'MODERATE_{side}' else: return 'NEUTRAL'

Window: 60 seconds
BUY ticks: 60
SELL ticks: 40
Total: 100

Imbalance = (60 - 40) / 100 = +0.20
Imbalance % = +20%
Heat Level = STRONG_BUY
Confidence = min(100/50, 1.0) = 1.0 (100%)

3SIGNAL GENERATION (SPEED + VOLTAGE)

Two independent signals are calculated in parallel using technical analysis (TA-Lib) and order imbalance. These signals drive all entry/exit decisions.

Signal 3A: SPEED (Entry Confidence)

Purpose: Quantify how confident we should be about entering a trade. Range: [-100, +100]

# From ECS_TradingSupervisor_Enhanced.py def generate_speed_signal(self, symbol, prices, imbalance): # Component 1: TA-Lib EMA Momentum ema_12 = talib.EMA(prices, timeperiod=12)[-1] ema_26 = talib.EMA(prices, timeperiod=26)[-1] momentum = (ema_12 - ema_26) / ema_26 * 100 # Percentage change # Normalize momentum to [-100, +100] momentum_normalized = np.clip(momentum, -100, 100) # Component 2: Order Imbalance Boost imbalance_boost = imbalance * 100 # Already in [0,100] range # Component 3: Weighted Combination (33 params control this) speed_signal = ( momentum_normalized * self.params['momentum_weight'] + imbalance_boost * self.params['imbalance_weight'] ) # Ensure valid range speed = np.clip(speed_signal, -100, 100) # Example calculation: # momentum = +25, imbalance = +35 # weight_momentum = 0.6, weight_imbalance = 0.4 # speed = (25 * 0.6) + (35 * 0.4) = 15 + 14 = +29 return speed

Signal 3B: VOLTAGE (Position Sizing)

Purpose: Determine how large a position to take based on volatility. Range: [-100, +100]

# From ECS_TradingSupervisor_Enhanced.py def generate_voltage_signal(self, symbol, prices, imbalance): # Component 1: TA-Lib ATR (Average True Range - volatility) high_prices = data['high'] low_prices = data['low'] close_prices = prices atr = talib.ATR(high_prices, low_prices, close_prices, timeperiod=14)[-1] current_price = close_prices[-1] # Normalize ATR to [-100, +100] # ATR typically 1-3% of price, so scale accordingly atr_normalized = min(atr / current_price * 100, 100) # Component 2: Order Imbalance Component imbalance_component = imbalance * 100 # Component 3: Weighted Combination voltage_signal = ( atr_normalized * self.params['volatility_weight'] + imbalance_component * self.params['imbalance_weight_volt'] ) voltage = np.clip(voltage_signal, -100, 100) # Example calculation: # atr_normalized = +25, imbalance = +35 # weight_volatility = 0.5, weight_imbalance = 0.5 # voltage = (25 * 0.5) + (35 * 0.5) = 12.5 + 17.5 = +30 return voltage

Step 3: Combine Signals

def generate_combined_signal(self, symbol, prices, imbalance, tick_count): speed = self.generate_speed_signal(symbol, prices, imbalance) voltage = self.generate_voltage_signal(symbol, prices, imbalance) signal = { 'symbol': symbol, 'speed': speed, # Entry confidence [-100, +100] 'voltage': voltage, # Position sizing [-100, +100] 'imbalance_pct': imbalance * 100, # Order flow [-100, +100] 'confidence': min(tick_count / 50, 1.0), # Data quality [0, 1] 'timestamp': datetime.now(), 'price': current_price } return signal # Example output: signal = { 'symbol': 'INFY', 'speed': +45, # Good confidence to enter 'voltage': +62, # Moderate position size 'imbalance_pct': +35, # Strong buy pressure 'confidence': 0.92, # High data quality 'timestamp': datetime(...), 'price': 1505.45 }

4ENTRY GATE (Threshold Validation) - Decision Point 1

Before entering a trade, 5 independent gates must ALL PASS. If any gate fails, the trade is automatically rejected (ABSTAIN). This is a cascade of fail-safe mechanisms.

Gate 1: Entry Confidence Threshold

Check if SPEED signal is strong enough to justify entry.

entry_threshold = self.params['entry_confidence_threshold'] # Calibrated, e.g., 35 if signal['speed'] >= entry_threshold: pass # Gate 1 PASS ✅ else: return False, "SPEED below threshold" # Gate 1 FAIL ❌

Gate 2: No Existing Position

Can only enter if not already in a position (single position per symbol).

if symbol in self.positions: if self.positions[symbol]['status'] == 'OPEN': return False, "Already in position" # Gate 2 FAIL ❌ pass # Gate 2 PASS ✅

Gate 3: Economic Viability (Profit > Costs)

Calculate projected profit target and stop loss. Ensure potential profit exceeds transaction costs.

# Calculate targets based on ATR and calibrated parameters atr_value = calculate_atr(symbol) profit_target = signal['price'] + (atr_value * self.params['profit_target_atr_mult']) stop_loss = signal['price'] - (atr_value * self.params['stop_loss_atr_mult']) # Calculate costs entry_cost = signal['price'] * 0.0005 # 0.05% brokerage + slippage exit_cost = profit_target * 0.0005 total_cost = entry_cost + exit_cost # Calculate potential profit potential_profit = profit_target - signal['price'] # Gate 3: Profit > Cost if potential_profit > total_cost: pass # Gate 3 PASS ✅ else: return False, f"Profit {potential_profit} ≤ Cost {total_cost}" # Gate 3 FAIL ❌

Gate 4: Chart Studies Signal

Composite signal from multiple technical studies (VWAP, EMA, momentum, volatility) must confirm entry.

chart_signal = self.get_chart_studies_signal(symbol) # Returns: 'GREEN' (buy), 'AMBER' (neutral), 'RED' (sell) if chart_signal == 'GREEN': pass # Gate 4 PASS ✅ else: return False, f"Chart signal is {chart_signal}" # Gate 4 FAIL ❌

Gate 5: Circuit Breaker

System-wide circuit breaker prevents trading during crisis conditions.

Final Decision: ALL GATES PASS → ENTRY APPROVED

def check_entry_conditions(self, symbol, signal): # Gate 1: SPEED >= threshold? if signal['speed'] < self.params['entry_confidence_threshold']: return False, "SPEED below threshold" # Gate 2: No existing position? if symbol in self.positions and self.positions[symbol]['status'] == 'OPEN': return False, "Already in position" # Gate 3: Profit > Cost? atr_value = calculate_atr(symbol) profit_target = signal['price'] + (atr_value * self.params['profit_target_atr_mult']) potential_profit = profit_target - signal['price'] total_cost = (signal['price'] + profit_target) * 0.0005 if potential_profit <= total_cost: return False, "Profit <= Cost" # Gate 4: Chart Studies GREEN? if self.get_chart_studies_signal(symbol) != 'GREEN': return False, "Chart signal not GREEN" # Gate 5: Circuit Breaker off? if self.circuit_breaker.is_halted(): return False, "Circuit breaker active" # ALL GATES PASSED ✅ return True, { 'profit_target': profit_target, 'stop_loss': profit_target - (2 * atr_value), 'potential_profit': potential_profit } # Example execution: signal = {'speed': +45, 'voltage': +62, 'price': 1505.45} passed, details = check_entry_conditions('INFY', signal) # Gate 1: 45 ≥ 35? ✅ YES # Gate 2: INFY not in positions? ✅ YES # Gate 3: 6.46 > 0.79? ✅ YES # Gate 4: Chart GREEN? ✅ YES # Gate 5: Circuit breaker off? ✅ YES # Result: ENTRY APPROVED ✅

Monitoring Loop (Runs per tick while position OPEN):

def monitor_position(self, symbol, current_price): """Called on every new tick while position is OPEN""" position = self.positions[symbol] entry_price = position['entry_price'] profit_target = position['profit_target'] stop_loss = position['stop_loss'] # Check Condition 1: Hit profit target? if current_price >= profit_target: return 'EXIT_PROFIT' # ✅ Exit signal # Check Condition 2: Hit stop loss? if current_price <= stop_loss: return 'EXIT_STOP' # ❌ Exit signal # Check Condition 3: Hold time exceeded? bars_held = current_bar - position['entry_bar'] max_hold = self.params['max_hold_bars'] # e.g., 60 bars if bars_held > max_hold: return 'EXIT_TIME' # ⏱ Exit signal # Check Condition 4: Circuit breaker triggered? if self.circuit_breaker.is_halted(): return 'EXIT_CIRCUIT' # 🛑 Exit signal # All conditions false → STAY IN POSITION return 'STAY' # Example tick-by-tick monitoring: # Entry: 1505.45 # Profit target: 1512.15 # Stop loss: 1500.82 # Max hold: 60 bars # Tick 1: 1505.50 → Between stop and target → STAY # Tick 2: 1506.10 → Between stop and target → STAY # Tick 3: 1508.20 → Between stop and target → STAY # Tick 4: 1512.20 → ≥ profit target 1512.15 → EXIT_PROFIT ✅

7EXIT EXECUTION (Close Position)

When an exit condition triggers, the position is closed at market price on the next bar (causally correct execution).

Exit Execution Logic:

def execute_exit(self, symbol, current_price, exit_reason): """Close position at market price""" position = self.positions[symbol] # Calculate P&L entry_price = position['entry_price'] quantity = position['quantity'] gross_pnl = (current_price - entry_price) * quantity # Deduct transaction costs (round-trip: entry + exit) costs = (entry_price + current_price) * quantity * 0.0005 # 0.05% each way net_pnl = gross_pnl - costs # Update position status position['status'] = 'CLOSED' position['exit_price'] = current_price position['exit_time'] = datetime.now() position['exit_bar'] = current_bar position['exit_reason'] = exit_reason position['gross_pnl'] = gross_pnl position['net_pnl'] = net_pnl # Update circuit breaker (tracks cumulative P&L for halt conditions) bars_held = position['exit_bar'] - position['entry_bar'] self.circuit_breaker.record_trade( pnl=net_pnl, entry_time=position['entry_time'], exit_time=position['exit_time'], bars_held=bars_held ) # Log logger.info(f"[EXIT] {symbol}: {exit_reason}, " f"gross={gross_pnl:.2f}, costs={costs:.2f}, net={net_pnl:.2f}") return position # Example exit: { 'symbol': 'INFY', 'entry_price': 1505.45, 'exit_price': 1512.20, 'quantity': 8, 'gross_pnl': (1512.20 - 1505.45) * 8 = 53.60, 'costs': (1505.45 + 1512.20) * 8 * 0.0005 = 12.07, 'net_pnl': 53.60 - 12.07 = 41.53, 'exit_reason': 'EXIT_PROFIT', 'bars_held': 23 }

📊 33 Key Parameters & Their Impact

These parameters are optimized through STAGE2 calibration (1,000+ iterations via Bayesian optimization) to maximize win rate on 3-year historical backtest.

entry_confidence_threshold
Stage 4, Gate 1
Minimum SPEED required to consider entry. Too low = too many bad trades. Too high = miss good trades.
Example: 35 means SPEED must be ≥35 to pass Gate 1.
profit_target_atr_mult
Stage 4, Gate 3
Multiplier for ATR to set profit target. Profit_target = Entry_price + (ATR × this_mult).
Example: 1.5 means profit target is 1.5× the ATR above entry price.
stop_loss_atr_mult
Stage 4, Gate 3
Multiplier for ATR to set stop loss. Stop_loss = Entry_price - (ATR × this_mult).
Example: 0.7 means stop loss is 0.7× the ATR below entry price.
momentum_weight
Stage 3, SPEED Calculation
How much EMA momentum contributes to SPEED signal. Higher = trust momentum more, trust imbalance less.
Example: 0.6 means SPEED = (momentum × 0.6) + (imbalance × 0.4).
imbalance_weight
Stage 3, SPEED/VOLTAGE Calculation
How much order imbalance boosts signals. Higher = rely more on microstructure, less on technicals.
Example: 0.4 means order flow gets 40% weight in SPEED.
volatility_weight
Stage 3, VOLTAGE Calculation
How much ATR (volatility) affects position sizing. Higher = scale up in volatile markets.
Example: 0.5 means ATR gets 50% weight in VOLTAGE.
max_hold_bars
Stage 6, Monitoring
Maximum bars to hold a position. Exit by time if this is exceeded.
Example: 60 means exit any position after 60 bars (~1 hour at 1-min candles).
base_quantity_per_symbol
Stage 5, Entry
Base position size, scaled by VOLTAGE. Larger = more aggressive position sizing.
Example: 10 means up to 10 shares, scaled down by VOLTAGE.
